# Jai Shree Balaji Screw House

A professional product showcase website for Jai Shree Balaji Screw House, built with Next.js, Tailwind CSS, Shadcn UI, and GSAP.

## Features

- **Hero Section**: Dynamic entrance animations and a QR code for easy sharing.
- **Product Gallery**: Versatile viewing options (Grid, List, Gallery) to browse products.
- **Product Details**: Interactive dialogs showing detailed product information.
- **Hardware Theme**: Custom industrial/electronics aesthetic.
- **Responsive Design**: Optimized for all devices.

## Tech Stack

- **Framework**: Next.js 15+ (App Router)
- **Styling**: Tailwind CSS v4
- **UI Components**: Shadcn UI
- **Animations**: GSAP
- **Data**: YAML-based product management

## Getting Started

1.  Install dependencies:
    ```bash
    pnpm install
    ```

2.  Run the development server:
    ```bash
    pnpm dev
    ```

3.  Open https://balaji-luxmi-three.vercel.app/store   with your browser to see the result.
